¿Qué son las extensiones de VS Code?

Visual Studio Code es, de base, un editor ligero. Lo que lo convierte en una herramienta capaz de adaptarse a casi cualquier lenguaje o flujo de trabajo son sus extensiones: pequeños complementos que añaden funciones nuevas al editor. Formatear el código al guardar, avisar de errores mientras escribes, autocompletar clases de Tailwind o mostrar quién cambió cada línea de un archivo: casi todo lo que echas en falta en VS Code existe ya como extensión.

Se instalan desde el propio editor, en el panel de extensiones (Ctrl + Shift + X, o Cmd + Shift + X en Mac), que se conecta al Marketplace de Visual Studio. Basta con buscar el nombre y pulsar Install.

¿Por qué son tan útiles?

  • Ahorran tiempo. Automatizan tareas repetitivas como dar formato, ordenar imports o cerrar etiquetas.
  • Reducen errores. Detectan fallos mientras escribes, antes de ejecutar el código o abrir el navegador.
  • Unifican el estilo. Todo el equipo escribe el código con el mismo formato, sin discusiones sobre comillas o tabulaciones.
  • Te ayudan a aprender. El autocompletado y la documentación al pasar el ratón te enseñan una librería mientras la usas.
  • Personalizan tu entorno. Temas, iconos y fuentes hacen que pasar horas delante del editor sea más agradable.

Calidad del código y formato

  • Prettier: formatea automáticamente tu código (HTML, CSS, JavaScript, TypeScript, JSON, Markdown) al guardar para mantenerlo limpio y uniforme.
  • ESLint: detecta errores, malas prácticas y problemas de sintaxis en tiempo real en JavaScript y TypeScript.
  • Prettier ESLint: combina las dos anteriores, formateando con Prettier y aplicando después las correcciones de ESLint.
  • Stylelint: el equivalente de ESLint para CSS, que avisa de propiedades erróneas, selectores duplicados y errores de estilo.
  • EditorConfig: aplica las reglas del archivo .editorconfig del proyecto (indentación, saltos de línea, codificación), sea cual sea el editor de cada persona.
  • Error Lens: muestra los mensajes de error y advertencias de los linters directamente en la misma línea del código, sin pasar el ratón por encima.
  • Pretty TypeScript Errors: reformatea los errores complejos de TypeScript para que sean mucho más fáciles de leer.
  • Code Spell Checker y Spanish - Code Spell Checker: detectan faltas de ortografía en el código y los comentarios, también en español.

HTML, CSS y maquetación

  • Live Server (o Live Preview): levanta un servidor local con recarga automática en el navegador cada vez que guardas cambios.
  • Auto Rename Tag: al cambiar el nombre de una etiqueta HTML de apertura, actualiza automáticamente la de cierre. VS Code ya trae algo parecido de serie con la opción editor.linkedEditing.
  • Tailwind CSS IntelliSense: autocompleta clases, muestra el CSS que genera cada una y detecta conflictos si trabajas con Tailwind CSS.
  • CSS Peek: permite ver y saltar a la definición de las reglas CSS directamente desde las clases del HTML.
  • BEM Helper: facilita escribir clases siguiendo la metodología BEM (bloque, elemento, modificador).

Archivos, imágenes y recursos

  • Path Intellisense: autocompleta las rutas de archivos al importar imágenes, scripts o estilos.
  • Image Preview: muestra una vista previa de la imagen al pasar el cursor por encima de su ruta.
  • SVG Preview y Better SVG: permiten previsualizar archivos SVG dentro del editor y, en el caso de Better SVG, optimizarlos con un clic.
  • Icomoon Viewer: muestra los iconos de Icomoon directamente en tus archivos de estilos.
  • PDF Preview: abre archivos PDF sin salir del editor.
  • Figma for VS Code: trae Figma al editor para inspeccionar diseños, consultar medidas y recibir notificaciones de los comentarios.

JavaScript, dependencias y APIs

  • Console Ninja: muestra los resultados de console.log y los errores en tiempo real junto a la línea de código que los genera.
  • Import Cost: indica cuánto ocupa cada dependencia que importas, para no inflar el tamaño de tu aplicación sin darte cuenta.
  • Version Lens: te indica en el package.json si hay versiones más nuevas de tus dependencias y te permite actualizarlas desde ahí.
  • REST Client: permite enviar peticiones HTTP y ver la respuesta directamente desde el editor, sin necesidad de Postman.

Control de versiones

  • GitLens: lleva la integración con Git a otro nivel, mostrando quién modificó cada línea, cuándo y en qué commit.
  • Git Graph: dibuja un gráfico con las ramas y commits del repositorio, desde el que también puedes hacer acciones de Git.

Markdown

  • Markdown All in One: atajos de teclado, vista previa, autocompletado e índices automáticos para que escribir Markdown suba de nivel.
  • Markdown PDF: convierte tus archivos Markdown a PDF, HTML o imagen.

Legibilidad y apariencia

  • Indent-rainbow: colorea cada nivel de indentación para que la estructura del código se lea de un vistazo.
  • Highlight on Copy: resalta brevemente el texto que acabas de copiar, para confirmar que has copiado lo que querías.
  • Material Icon Theme: colección de iconos para identificar cada tipo de archivo y carpeta en el explorador.

Inteligencia artificial

  • GitHub Copilot: asistente de inteligencia artificial que sugiere código, genera pruebas y documentación y responde preguntas sobre tu proyecto.
  • GitHub Copilot modernization: ayuda a actualizar aplicaciones antiguas y a migrarlas a la nube de Azure.

Configurarlas bien

Muchas extensiones funcionan nada más instalarlas, pero sacarles partido suele requerir algún ajuste en settings.json. Por ejemplo, para que Prettier formatee cada archivo al guardarlo: 

{
    "editor.defaultFormatter": "esbenp.prettier-vscode",
    "editor.formatOnSave": true
}

Si trabajas en equipo, puedes recomendar extensiones a todo el que abra el proyecto creando el archivo .vscode/extensions.json. VS Code mostrará un aviso para instalarlas: 

{
    "recommendations": [
        "esbenp.prettier-vscode",
        "dbaeumer.vscode-eslint",
        "bradlc.vscode-tailwindcss"
    ]
}

Con moderación

Las extensiones son tan fáciles de instalar que es tentador acumularlas, pero cada una consume memoria y puede ralentizar el arranque del editor. Algunas recomendaciones:

  • Comprueba si ya viene integrado. VS Code incorpora con el tiempo funciones que antes requerían extensiones, como colorear las parejas de corchetes o renombrar etiquetas HTML.
  • Fíjate en quién la publica. Una extensión tiene acceso a tus archivos, así que conviene elegir las de editores verificados y con muchas descargas.
  • Instala solo lo que uses. Revisa tu lista de vez en cuando y desinstala lo que ya no necesites.
  • Desactívalas por proyecto. Desde el panel de extensiones puedes desactivar una solo en el espacio de trabajo actual.
  • Usa perfiles. Los perfiles de VS Code te permiten tener conjuntos de extensiones distintos, por ejemplo uno para frontend, otro para Java y otro para Python.
  • Vigila su impacto. El panel de extensiones muestra cuánto tarda cada una en activarse; si alguna tarda segundos, plantéate si la necesitas siempre activa.

Conclusión

Las extensiones convierten VS Code en un editor hecho a tu medida. Con unas pocas bien elegidas escribirás más rápido y con menos errores. Empieza por las básicas de calidad de código, como Prettier y ESLint, y ve añadiendo las demás a medida que las necesites.
